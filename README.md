# KINOWEB

Платформа для просмотра фильмов и сериалов.

**Слоган:** Смотри лучшее.

## О проекте

KINOWEB — современный сайт для просмотра аниме, фильмов и сериалов с удобным интерфейсом, системой статусов просмотра, комментариями и сообществом.

## Основные возможности (в разработке)

- Каталог фильмов и сериалов
- Система статусов: Смотрю / В планах / Просмотрено / Отложено / Брошено
- Избранное
- Поиск и фильтры
- Комментарии и оценки
- Community-лента (для подписчиков)
- Админ-панель для основателей
- Подписки Premium

## Технологии

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Drizzle ORM
- Clerk (авторизация)
- Neon / PostgreSQL
